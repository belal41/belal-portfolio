# Belal Bakry Ahmed — Personal Portfolio

Static, responsive portfolio built from the information and uploaded project/certificate files provided.

## Run
Open `index.html` in a modern browser.

If your browser blocks ES modules from local files, run a simple local server from this folder, e.g.:
`python -m http.server 8000`

Then open `http://localhost:8000`.

## Update projects
Edit `data/projects.js`. The UI renders the cards automatically.

## Update certificates
Edit `data/certificates.js`. The UI renders the cards automatically.

No project GitHub/demo/Power BI URLs were added because none were provided in the uploaded project PDFs. No certificate verification URLs were added because none were provided.
